# 90-second demo script

This script is for a release with a completed proof journal. If any case is still pending, show the pending state in the Transactions page and identify the case as pending. Do not narrate an expected result as a finalized result.

**0:00–0:12 — The desk.** Open the home page without a wallet. Explain that a policy change only appears in the ledger after finality, the challenge window and payout readback. Point out the StudioNet network label.

**0:12–0:28 — A catch.** Open the Zoom historical case. Show the frozen concern and compare the archived baseline with the later passage. Follow both Wayback `id_` links and read the criterion verdict and validator quote.

**0:28–0:42 — Settlement.** Show the closed challenge window, payout amount, recipient and native credit readback. Open the case transaction and direct contract address in the StudioNet Explorer.

**0:42–0:54 — A rejected cosmetic change.** Open the date-only case. Show that the archived text changed but the frozen criterion was `NOT_TRIGGERED`; code did not award a bounty for a cosmetic edit.

**0:54–1:06 — Challenges.** Compare the upheld and rejected challenge cases. Explain that the challenger chooses `ALREADY_EXISTED` or `WRONG_DOCUMENT`, and that the contract applies the bond rule after the finalized ruling.

**1:06–1:18 — Current docket.** Open the live watch page. Choose one current watch and show its baseline timestamp, frozen criteria, funded bounty and expiry. Clearly distinguish production watches from historical replays.

**1:18–1:30 — Receipts and limits.** Open the transaction log and show finalized receipts. State the total recorded native deposits and the 0.1 GEN cap. Finish with the proof verifier output and the separate Explorer address evidence entries for the deployed contracts.
